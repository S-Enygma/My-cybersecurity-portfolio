# Experience Learned

	- Alert prioritisation (sort by severity, not by arrival):
		I mostly worked the queue in the order alerts appeared, despite they were labeled by severity. Considering Higher severity alerts first can hugely improve efficiency. 
	- Search wide, then narrow :
		My first Splunk search missed the reverse shell because I restricted the time scope too much. Widening it first, and then filter by narrowing while progressing is a better practice.
	- Use the playbook as reference : 
		I almost missed some important informations for proper classification allthough  they were in the documentation. I mistakenly classified some of the False Positive alerts as True.
	- Anybody can be exposed: Some people might thing such thing could never happen to them but the reality is that attackers are getting smatter. Thus, we need to ensure that every one do is 
	 due diligence by learning the good practices to train our cybersecurity awerness.
