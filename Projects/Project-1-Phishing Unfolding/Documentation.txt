Getting ready to step into the shoes of a Security Operations Center (SOC) analyst. This platform simulated real-world scenarios where i received alerts, investigated them as needed, and took appropriate actions to resolve or close them.

# Alert triage Playbook
  Initial Alert Review:

    - Accessing the SOC Dashboard: Open the SOC dashboard and review the new alerts
    - Assigning Alert to Myself: Add the first (earliest) alert to the list of assigned alerts
    - Understanding Alert Logic: Review the alert description and understand its logic
    - Reviewing Alert Details : Looking at the IOCs provided in the alert, like IPs and domains

  Investigation in the SIEM: Microsoft sentinel / Splunk / ElasticSearch

    Accessing the SIEM: see raw security events that triggered the alert
    Query Related Logs: gather more context and build the activity timeline
    Use Analyst VM: check the threat score of found indicators via the TryDetectThis app
    Correlate and Validate: Correlating the alert data with other data sources to validate the credibility of the alert

  Resolution and Closure:
  
    Decide on Alert Classification: follow the Alert Classification guide
    Write Case Report: Provide a detailed report of the triaged alert according to the Alert Reporting guide
    Decide if Alert Requires Escalation: For True Positives, refer to the same guide and follow the Escalation section
    Submit and Close the Alert: Once the alert is triaged, submit and close its case report in the SOC dashboard

# Alert Classification
	True Positive

		Classification for unauthorised access to information, threats like malware, adware, phishing, brute force, account breach, or an action that violates the company’s security policies. 

	False Positive

		Classification for activities which were determined to be legitimate, meaning those that did not have malicious intent, can’t harm the organisation, and don’t violate the security policies. 
		
# Alert Reporting

	Provide a clear and detailed explanation of the reason why the activity is classified as TP or FP
	Clearly explain why the alert requires escalation and which remediation actions may be required
	Specify the entities associated with the activity detected by the alert:
		Identify who or what was affected
		Indicate where the activity occurred
		Clarify when the activity took place via the timestamps
	Provide all IOCs associated with the activity:
		Network Indicators: IP addresses, Ports, Domains, URLs, etc
		Host Indicators: File Names, File Paths, Hashes, Signatures, etc.
	Specify which goals the threat actor attempted to achieve
	May Specify which MITRE techniques or tactics the activity can be related to
